## How to launch a lane (proven pattern)

```
ACCEPTED_ENGINE_MD5=<base tree md5> /root/bin/needle-board run <b> -- bash -c \
  'bash /workspace/esp32-needle-3/.auto/gen_lane.sh <b> <generator> <target> [gen2 tgt2]'
```

inside a tmux session, log to `/root/board-pool/batches/<tag>.log`. `gen_lane.sh` asserts the base
tree, deletes tracked `.auto/diag_*` markers, asserts each target actually changed, writes
`expect_engine_md5`, and takes an optional second (generator,target) pair for bundles. Lanes sync
main's **committed** branch only — commit before pricing a stack. Never `reset --hard` a worker
without checking `git status --porcelain` (a pathspec stash that names an untracked path aborts and
then the reset destroys work — it happened to board 1 this session).
