# Glossary

**Accepted pin**  
The owner-promoted comparison tree that passed its full required gates. In this
snapshot it is commit `2c79104` at 5.3033 decode tok/s, not the faster proposed
trees.

**Anti-repeat guard**  
Harness logic that rejects an already measured firmware/engine signature unless
a deliberate-repeat override and reason are provided.

**Breadth gate**  
The full frozen device prompt suite, currently 20 cases. A primary-only screen
is narrower and cannot promote a candidate.

**Cactus Quants (CQ)**  
The model's block quantization scheme. Logical weights combine small packed
codes, a per-group norm, and a Hadamard-domain representation. CQ2 and CQ4 use
two and four bits per code respectively.

**Candidate**  
A measured, preserved result that has not been owner-promoted or still has a
named unresolved gate. It must not be described as accepted/shipped.

**CQ2 pair LUT**  
A lookup table that precomputes the activation contribution of two 2-bit codes.
One nibble selects one of 16 pair combinations, amortizing multiply/decode work
across rows.

**Diagnostic image/result**  
An instrumented, kbench, profile, or mechanism-isolation build. It can establish
cause but is not a shipping throughput number without a clean rebuild.

**EG2**  
Late narrow staging of one engram operand/pair. It measured about +0.164%, below
the direct keep bar, and depended on compact-prefix memory.

**Engram**  
The model's hashed/subspace memory component, configured in the sliced archive
with tables, slots, taps, dilation, orders, and injection sites.

**Evidence packet**  
The provenance, raw logs, metrics, correctness gates, hashes, and mechanism
proof required to interpret one result.

**External handoff**  
A router result naming a configured remote model/capability. This implementation
stops at selection and does not call that provider.

**FWHT / Hadamard transform**  
Fast Walsh–Hadamard transform. It maps activations into the orthonormal domain
used by the quantized weight representation and appears in Monarch MLP factors.

**Golden**  
A frozen expected artifact: host/device generated bytes or a logit reference.
It is an oracle under a defined model, state, transport, and ordering policy—not
permission to overwrite any disagreement.

**GQA**  
Grouped-query attention. Needle 3 has 12 query heads and two KV heads in the
sliced model.

**IRAM / DRAM / PSRAM**  
ESP32 internal instruction memory, internal data memory, and external pseudo-
static RAM. Placement names imply different capacity, latency, cache, and DMA
properties.

**Keep bar**  
The campaign's minimum worthwhile integrated speed improvement, generally
0.2%. A smaller change can be banked as an enabler but should not be presented
as a standalone win.

**Kbench**  
Target kernel microbenchmark/differential firmware. It establishes local timing
and numerical behavior but does not replace integrated request measurement.

**KV window**  
The finite attention key/value history. This model stores an int8 KV cache with
a 256-token window inside a 384-token overall sequence limit.

**mHC**  
The model's multi-lane hyper-connection/residual mechanism. This archive uses
four lanes; its recurrent state must be included in prefix snapshots.

**Monarch MLP**  
The model's structured feed-forward path using staged factors and Hadamard
transforms rather than a conventional pair of dense matrices.

**N32R16**  
Module shorthand for 32 MiB flash and 16 MiB PSRAM. Confirm actual hardware;
the family name alone is insufficient.

**Own-tree differential**  
A kernel-versus-reference test built from the exact tree that carries the
candidate. It avoids borrowing a green microtest from a similar lineage.

**Phase map**  
Instrumented timing attribution used to find a bottleneck. Categories can nest
or overlap and therefore may not sum to 100%.

**Prefix snapshot/cache**  
Saved state after evaluating a fixed schema/system prefix. Correct restoration
includes KV, convolution, engram/mHC and positional state, not just tokens.

**Primary / ext / think**  
Primary is the tuned constrained benchmark group; `ext` is a held-out prompt
monitor; `think` is an unconstrained/full-vocabulary monitor. Their joint
movement helps distinguish kernel gains from workload-specific effects.

**Provenance proof**  
Evidence that the intended source, flags, object, linked code, binary, model,
board, and production path were actually measured.

**RX ring**  
The interrupt-fed/lossless receive buffering change that fixed long requests.
It is also the exact transport discriminator for the two disputed device
goldens.

**Shipping line / seed line**  
Two preserved engine ancestries. A lever's sign and correctness on one do not
automatically transfer to the other.

**TIE728**  
Project shorthand for the ESP32-S3 Xtensa/TIE target assembly kernel family,
especially the handwritten CQ2 walker. It does not mean generic portable SIMD.

**Token delta**  
Aggregate difference in generated token IDs/length as reported by the harness.
Passing final cases have zero; the two disputed cases total 52.

**Tree A / B / C**  
The three final preserved candidates: B3 6.1433, B2 6.1250, and B1 5.9033
tok/s. Letters describe campaign artifacts, not Git branches guaranteed in the
main checkout.

**ZC-RMS**  
The model's zero-centered/root-mean-square normalization variant used around
attention/MLP residual paths.
